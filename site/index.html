Agents that see the room

Real footage, a real detector, a real model, a real memory — live in this page.

This is the pipeline an Atlas desk runs when cameras are one of its inputs. Stock footage from a shop, a stock room, a factory, a clinic and an office rotates as if it were seven cameras on one site. YOLOv8n runs in your browser on every frame. Every few seconds the frame and the counts go to the vision model, which narrates what it sees — streamed token by token. Each narration becomes an event in the log, and you can ask questions across all the cameras: the answer is retrieved from that log and cites the events it used.
